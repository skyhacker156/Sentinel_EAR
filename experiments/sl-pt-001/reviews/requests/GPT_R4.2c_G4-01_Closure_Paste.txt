- **requests:** the TER has exactly two request objects, `bars_request` and `quote_request`, each `{url, sent_at, received_at, outcome}`. A request that was issued has `url` and `sent_at` as strings, and `outcome` ∈ {`RESPONSE`, `NO_RESPONSE`}. `received_at` is a string when `outcome` = `RESPONSE`, and `null` when `outcome` = `NO_RESPONSE` (issued, but no HTTP response received). A request with `NO_RESPONSE` has a `null` artifact hash;
- **collections** (per-bar token tuples, excluded bars, bar-store transitions, rule results) are JSON arrays, **always present**. They are the empty array `[]` when there is nothing to record, including when the bars were never fetched or never parsed;
- **scalars:** `null` is the only non-string **scalar** value permitted in a TER. Objects and arrays are structure, not numbers.
